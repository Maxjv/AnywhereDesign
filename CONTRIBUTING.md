Thank you for your interest in contributing to AnywhereDesign!

## Development Workflow

1. Fork the repository on GitHub.
2. Create a feature branch: `git checkout -b feature/my-enhancement`.
3. Ensure all code conforms to modern JavaScript (ES6+) standards without adding unnecessary external dependencies.
4. Keep the **Local-First Manifesto** intact: no telemetry, no tracking pixels, no unexpected network calls.
5. Commit your changes with clear, descriptive commit messages.
6. Push to your branch and open a Pull Request.

For major architectural proposals, please open an Issue first to discuss the design before writing code.
